Design system and UI kit

Evidence File

Knowledge Warranty as a dossier. What was said is set like testimony, when it was said is set like a reference number, and current or replaced is stamped, not coloured in.

01

Principles

Quote first

The spoken words are the largest text in an answer.

Our own sentence is a caption for the evidence, never the other way round.

Rules, not boxes

Hairlines group, heavy rules open a section.

No shadows, no rounded cards. Paper, lines and whitespace.

Stamps

State is stamped in a colour, like a mark on a file.

Teal current, amber replaced, red refused. Outlined, never filled.

02

Colour roles

Same palette. Surface white dominates; black is for ink and rules, not bands.
