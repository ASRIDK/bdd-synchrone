Design system and UI kit

Control Room

The archive as a live system. The interface is a console: panels, status lamps, timecodes. The evidence itself is the one light surface, so it is always the brightest thing on screen.

01

Principles

Console around evidence

Dark chrome, light proof.

Navigation, trace and stats are dark. Quotes sit on a white card, so the eye lands there.

Lamps

State is a light, not a word.

Red on air or refused, teal current or passed, amber replaced. Every lamp has a label next to it.

Timecode native

Every citation starts with its time.

The timecode block leads the row and is the play control.
