The answer is an audit record. One monospace face, 1.5 px black borders, square corners, tables before cards. Nothing is decorative; everything can be copied into a ticket.

principles

01auditable

Everything is a record.

Every answer, step and import is a row with an id, a time and a status.

02borders

Structure is drawn, not implied.

Black borders around every region. No shadows, no radius, no fills except state.

03brackets

State reads as text.

current replaced refused. Colour confirms, the word decides.
